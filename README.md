# GitHub User Guide

How the College of Education's development team works on GitHub. The current version of the standard is the GitHub Standard chapter in the ETC Web Team Wiki. This repository holds a copy of it.

- [`GitHub-Standard.md`](GitHub-Standard.md): the standard.
- [`templates/`](templates/): the files a new repository starts from (standard §4.1). The same files are in `CoE-Config`.
- [`command-line-instructions.md`](command-line-instructions.md): the earlier command-line guide, kept for reference. Getting set up is now §1.1 of the standard.
- [`archive/README-2025.md`](archive/README-2025.md): this repository's previous README, unchanged.

This copy is updated whenever the standard changes.
